# Code of conduct

Nota follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the code, not
the person. Harassment, insults and personal attacks aren't allowed in issues,
pull requests or anywhere else in the project.

To report a problem, contact the maintainer privately through
[GitHub](https://github.com/Nirzhuk). Reports are kept confidential.
