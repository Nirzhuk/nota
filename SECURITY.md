# Security

Please don't report security problems in public issues.

Report them privately with GitHub's
[security advisory form](https://github.com/Nirzhuk/nota/security/advisories/new).
You'll get a reply within a week.

Things worth reporting:

- A website being able to read or write your notes through the app's local
  server on `127.0.0.1:4317`.
- The extension sending data anywhere other than that local server.
- A way to get the updater to install a build that wasn't signed by the
  project's key.

Only the latest release gets fixes.
